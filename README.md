# mycomfy

EC2 上で ComfyUI を必要なときだけ起動して使うための、自前運用一式。
普段はインスタンスを停止し、モデルは AMI や EBS に持たず、起動時に S3 から取得する。

## 運用原則

- **普段は停止**：使うときだけ起動し、終わったら止める。コンピュート課金は稼働時間だけ。
- **自前 AMI は持たない**：ベースは AWS 公式の Deep Learning AMI。環境は cloud-init と S3 上のバンドルで再現する。
- **モデルは起動時取得**：モデル類は S3 に置き、起動時にインスタンスストアへ同期する。AMI／EBS に焼かない（保持費を払わない）。
- **調整済みに乗る**：モデルのマージやチューニングは自分でやらない。配布されている調整済みチェックポイントと公開レシピを使う。
- **エラー通知は notify-me 経由**：起動時などの失敗は SNS へ publish し、別リポジトリの notify-me（SNS → SQS → Lambda → LINE）で受け取る。このリポジトリに通知の実装は持たない。

## ディレクトリ構成

| パス | 中身 |
|---|---|
| `infra/terraform/` | EC2（スポット、起動テンプレート含む）／S3／IAM などインフラの定義 |
| `boot/cloud-init/` | 初回起動時の user-data（per-boot サービスの登録まで） |
| `boot/systemd/` | 起動のたびに動くユニット（モデル同期、ComfyUI 起動、失敗時通知の配線） |
| `boot/scripts/` | 起動処理の実スクリプト（同期、起動、失敗通知） |
| `bundle/` | ComfyUI＋カスタムノード＋venv を版固定で固めたバンドルの作成手順とスクリプト |
| `models/` | モデル取得マニフェスト（実ファイルは置かない。S3 側に置く） |
| `workflows/api/` | 実行用ワークフロー（API 形式 JSON） |
| `workflows/ui/` | 編集用ワークフロー（UI 形式 JSON） |
| `tools/comfy-tools/` | 補助 CLI（マニフェスト検証、バンドル作成補助など。uv ワークスペース） |
| `ui/` | 簡易 UI（プロンプト文だけを入力する薄い Web UI。後段で実装） |

ルートには全体の入口ファイルだけを置き、実装は各ディレクトリの中に置く。
